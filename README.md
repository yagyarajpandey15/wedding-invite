# Abhishek & Simran - Wedding Invitation

An interactive, mobile-first digital wedding invitation card for **Abhishek Kumar & Simran Choudhary**.

## Features
- **Cinematic Card Opening:** Tap anywhere to play the wax-sealed envelope opening animation with smooth reveal.
- **Interactive Scratch Card:** Scratch-to-reveal gold foil wedding date (`11 . 02 . 2027`).
- **Live Event Itinerary:** Tilak, Haldi (video), Mehndi & Mocktails, Wedding Ceremony (Jaimala), Grand Feast, and Vidaai (Doli).
- **Google Maps Integration:** Embedded venue location with Google Plus Code (`G7C7+747 Menhan, Bihar, India`) and one-tap navigation.
- **Atmospheric Background Music:** Soft romantic melody player with play/pause controls.
- **Interactive Modals:** Venue directions, RSVP blessings, and Sangeet celebration playlist.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
